# Homebrew tap for Sparewall

The [Sparewall](https://github.com/sparewall/sparewall) CLI, `sparewall`,
for macOS and Linux (x86_64 and arm64):

```shell
brew install sparewall/tap/sparewall
```

`Formula/sparewall.rb` is written by the release workflow in
[sparewall/sparewall](https://github.com/sparewall/sparewall) each time a
release is published (`.github/homebrew-formula.sh`); changes made here
directly are overwritten. Report problems in that repository.
